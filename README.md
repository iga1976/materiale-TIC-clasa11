# Materiale TIC – Documente pentru clasa a XI-a și studiu individual

Acest repository conține materiale pentru orele de TIC:
- Documente Word
- Fișiere Excel
- Prezentări PowerPoint
- Baze de date Access

## Structura folderelor
- **Word/** – invitații, fișe de lucru, modele de documente
- **Excel/** – tabele, exerciții, baze de date simple
- **PowerPoint/** – prezentări pentru curs și proiecte
- **Access/** – baze de date și exemple de proiecte

## Cum descarci fișierele
1. Deschide folderul dorit
2. Selectează fișierul
3. Apasă pe **Download**

Nu este nevoie de cont GitHub pentru a descărca.

## Cum contribui
Dacă dorești să adaugi materiale:
- Creează un cont GitHub
- Trimite un *pull request*
- Sau cere acces ca *collaborator*
